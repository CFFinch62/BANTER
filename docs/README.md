# Docs

Anything you put in this folder is reference material your project can pull
up **inside BANTER** instead of switching to a browser or another app.

## How it works
- Browse to this folder in the file browser (left-hand pane) and double-click
  a file — supported types (`.md`, `.txt`, `.html`/`.htm`) open in the
  **documentation pane** on the right instead of an editor tab.
- The pane is tabbed, so you can have several reference docs open side by
  side, and it stays full height regardless of where the console is docked.
- Toggle the pane's visibility from **View → Toggle Documentation**.

## What to stage here
- Smalltalk language references, stdlib notes, style guides
- Design notes for whatever you're building with BANTER
- Anything you'd otherwise keep alt-tabbing to a browser for

## Markdown features
This viewer supports standard Markdown: **bold**, *italic*, `inline code`,
lists, and links.
